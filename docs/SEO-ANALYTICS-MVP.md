# GLOBUS 2027 — SEO Analytics MVP

Статус: проектирование, без доступа к Google и без развёртывания.
Ветка: feature/seo-analytics-foundation.

## Цель
Внутренний раздел «SEO-аналитика» в GLOBUS Workspace. Отдельный фоновый сборщик получает статистику только сайта globus-k.kz через официальный Google Search Console Search Analytics API. Публичный сайт не участвует в сборе.

## Первый источник
Google Search Console: property ID берётся из списка доступных ресурсов после авторизации (не предполагать автоматически, что это domain property). OAuth 2.0, минимальный scope https://www.googleapis.com/auth/webmasters.readonly. Refresh token хранить только на сервере в секретах, шифровать при хранении; не помещать в Git, браузерные логи или клиентский код. Доступ только администратору Workspace.

## Расписание и периоды
Каждое 3-е число в 09:00 Asia/Almaty — сбор за предыдущий календарный месяц. Перед фиксацией проверять доступность окончательных данных; если неполные — помечать предварительными и повторять позже. Повторять неудачные запросы с экспоненциальной задержкой. Дополнительный пересбор последних 7–14 дней для учёта задержки данных. Использовать идемпотентную запись (upsert), чтобы повторные запуски не удваивали статистику.

## Сохраняемые показатели
Для каждого дня: clicks, impressions, CTR, position. Для отчётов — разрезы query и page (при необходимости device/country); API может скрывать анонимизированные запросы и ограничивать число строк, поэтому сумма строк запросов не обязана равняться общему числу кликов. Общие показатели запрашивать отдельно без dimensions. CTR = clicks / impressions, позиция — взвешенная метрика из API; не усреднять месячные CTR и позиции арифметически.

## Минимальная модель данных
seo_sources(id, provider, property_id, status, last_success_at)
seo_runs(id, source_id, period_start, period_end, status, started_at, finished_at, error)
seo_daily(source_id, date, clicks, impressions, ctr, position, data_state; unique(source_id,date))
seo_dimension_daily(source_id, date, dimension_type, dimension_value, clicks, impressions, ctr, position; unique(source_id,date,dimension_type,dimension_value))
seo_change_log(id, date, url, description, category) — журнал SEO-изменений, вводимый вручную/из подтверждённых изменений.

## Интерфейс Workspace
Карточки: клики, показы, CTR, средняя позиция, изменение к предыдущему сопоставимому периоду; график по дням; таблицы запросов и страниц; журнал SEO-правок; статус последней синхронизации и ошибки. Сравнение полных календарных месяцев и произвольных равных периодов. Доступ только авторизованному администратору.

## Критерии приёмки
1. OAuth с правами только на чтение; доступ к ресурсу подтверждён.
2. Тестовый ручной сбор одного завершённого периода.
3. Повторный сбор не создаёт дубликатов.
4. Итоги совпадают с Search Console в пределах известных особенностей API/задержки данных.
5. Планировщик выполняет задачу без открытого ChatGPT.
6. Секреты не доступны из браузера и репозитория.
7. Ни одна задача сбора не влияет на публичный сайт.
