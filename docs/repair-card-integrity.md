# GLOBUS 2027 — Контроль целостности и полноты карточек ремонта

Статус: утверждённое направление, кандидат на реализацию; не означает публикацию.
## Инварианты
- Семь вкладок: Обзор, Параметры, Диагностика, Команды, Логи, Прошивки, Фото.
- Заводские параметры: manufacturer, pcb (индекс, ревизия, дата), sticker, soc, ram, emmc. Замены только в диагностике. Для каждого поля хранить значение, статус (known / unknown / not_provided / not_applicable / error) и источник. Не подменять неизвестное догадкой.
- Сохранить исходный boardParameters без изменений; миграция добавочная, идемпотентная, без перезаписи конфликтов. Неоднозначные строки направлять на ручную сверку. Старый клиент не должен затирать новые поля. Чтение и запись через единый адаптер.
- Перед сохранением составлять реестр полученных материалов и их назначений. Каждый лог — независимая запись, полный оригинал, связь с источником; крупный лог может читаться из R2 без дублирования в D1. Файлы: размер и SHA-256, связь с карточкой, без дублей. Карта USER: номер, название, Offset HEX, Length HEX; исходная и изменённая карты отдельно; неизвестная длина явно обозначена.
## Проверки
1. Сверить входной реестр с фактически сохранёнными полями, этапами, логами, картами и файлами.
2. Повторно прочитать D1 по ID и ревизии; сравнить значения, количество и длины записей. R2 проверить по размеру и SHA-256.
3. Проверить все семь вкладок в браузере после перезагрузки. Успешный API не доказывает корректное отображение.
4. Раздельные статусы ремонта и документации. Полнота документации: complete / incomplete / verification_pending; ошибки хранения и отображения отдельно. Не блокировать сохранение черновика или техническое завершение ремонта из-за неизвестных сведений.
5. Подтверждение завершения переноса только при отсутствии необъяснённых расхождений. Явно сообщать непроверенные пункты.
## Приёмочные тесты на изолированном стенде
- Все шесть полей заполнены, в том числе кириллица, длинные маркировки и альтернативные подписи в legacy-тексте; сохранение и перезагрузка не меняют значения.
- Неизвестные параметры и конфликт миграции видимы; исходный текст сохранён.
- Три независимых UART-лога, один большой; полный текст доступен, поиск и скачивание не сокращают оригинал.
- Две карты по 25 разделов: порядок, смещения и длины совпадают с источником.
- Фото и текстовые оригиналы: совпадение SHA-256, повторная загрузка не создаёт дубль; отсутствующий объект явно отмечен.
- Конкурентное редактирование: конфликт ревизий не затирает данные.
- Повторная миграция не изменяет результат; откат к старому интерфейсу не уничтожает новые поля.
- Windows и Android: все вкладки читаемы, параметры и вложения доступны.
