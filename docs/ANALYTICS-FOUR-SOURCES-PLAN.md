# GLOBUS 2027 — единый агент аналитики globus-k.kz

Статус: техническая спецификация; интеграции не авторизованы и не запущены.
Область: **только globus-k.kz** (включая соответствующие варианты ресурса, подтверждённые владельцем).
Цель: отказаться от платных сборщиков данных; использовать официальные API, хранить историю и выдавать ежемесячные отчёты в закрытом GLOBUS Workspace.

## Источники и доступ

| Источник | API | Авторизация | Данные |
|---|---|---|---|
| Google Search Console | Search Console API / Search Analytics | OAuth, webmasters.readonly | клики, показы, CTR, позиции, запросы, страницы, устройства, страны |
| Google Analytics 4 | Google Analytics Data API | OAuth с analytics.readonly либо service account с разрешённым доступом к GA4 property | пользователи, сессии, источники, вовлечённость, ключевые события |
| Microsoft Clarity | Clarity Data Export API (при доступности проекта и соответствующих метрик) | токен API в серверном секрете | доступные агрегаты поведения; не обещать выгрузку всех записей сессий/тепловых карт |
| Google Ads | Google Ads API / GAQL | OAuth, developer token, customer ID, при необходимости login-customer-id | расходы, клики, показы, CPC, кампании, конверсии |

Официальные API могут иметь квоты, требования допуска и ограничения; отсутствие платы за посредника не гарантирует отсутствие расходов на инфраструктуру. Google Ads API требует отдельного допуска. Не выполнять браузерный скрейпинг личных кабинетов и не запрашивать пароли в чате.

## Принципиальная архитектура

1. Изолированный серверный collector (отдельный Worker/процесс), не публичный сайт.
2. Четыре независимых адаптера: gsc, ga4, clarity, google_ads. Отказ одного не блокирует остальные.
3. Серверный секретный стор для OAuth refresh tokens / API tokens; ни в Git, ни в D1 в открытом виде.
4. Сбор ежедневных агрегатов и отдельных срезов; в каждой записи provider, source_id, дата, размерность и время обновления.
5. Дедупликация по естественному ключу, UPSERT, журнал запусков, ошибки и состояние полноты данных.
6. Планировщик, работающий без открытого ChatGPT: 3-го числа в 09:00 Asia/Almaty для предыдущего месяца, с повторным обновлением последних дней; часовой пояс и UTC-конвертацию проверять в настройках среды.
7. Закрытый dashboard Workspace и ежемесячный отчёт с раздельными разделами по каждому источнику и общими рекомендациями.

## Данные, которые нельзя смешивать

- GSC «клики из поиска» != GA4 «сеансы из органики»; различаются определения, атрибуция и задержки.
- Clarity «dead clicks/rage clicks» не заменяют GA4 конверсии.
- Ads расходы/клики не равны GA4 paid sessions и не должны суммироваться с ними.
- CTR, CPC, среднюю позицию и engagement rate пересчитывать из агрегированных числителей/знаменателей, а не арифметически усреднять дневные коэффициенты.
- Все суммы расходов хранить с кодом валюты аккаунта; временные зоны GA4/Ads могут отличаться от Asia/Almaty.
- Отсутствие доступа к источнику отражать как «не подключён», а не нулевые показатели.

## Этапы внедрения

1. **Инвентаризация**: найти реальный репозиторий/исходники Workspace, Cloudflare D1 bindings, Worker routes, auth и миграции. Подключение GLOBUS через ChatGPT даёт операции с карточками, но не право изменять схему D1.
2. **Безопасная база**: отдельные таблицы seo_* и analytics_* без изменений существующих repair/equipment/history/attachments; резервная копия до миграции.
3. **GSC**: авторизация, первый ручной сбор, сверка цифр, идемпотентность.
4. **GA4**: авторизация и сверка пользователей/сеансов/конверсий.
5. **Clarity**: токен, проверка доступных показателей, сбор.
6. **Google Ads**: developer token и customer ID, проверка доступа, расходы и кампании.
7. **Автоматизация и отчёты**: независимый cron, повторные попытки, мониторинг ошибок, сравнение месяцев, экспорт CSV/Excel/PDF при необходимости, вывод в Workspace.

## Приёмка

- Подтверждено, что все четыре источника относятся к globus-k.kz.
- Каждый источник независимо собирается и сверяется с оригинальным кабинетом.
- Повторный сбор не создаёт дубли и не затирает чужие данные.
- Система продолжает работать при закрытом ChatGPT.
- Существующие карточки ремонтов, оборудование, фотографии, файлы и история не изменены.
- Доступ к аналитике только у владельца/администратора.
- Есть явные статусы «не подключён», «сбор идёт», «готово», «ошибка», «данные предварительные».

## Текущее состояние

Созданы проектные документы и черновик SQL для GSC в ветке feature/seo-analytics-foundation. **Ни один API пока не подключён; база не изменена; код сборщика не развернут.** Схему GSC необходимо расширить до общей мульти-источниковой схемы перед реальной миграцией.
